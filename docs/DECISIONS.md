# Decisions

Questions from the product brief that change the schema or behaviour. The daily
build run builds with the **provisional answer** until the product owner fills
in **Confirmed**. It never changes this table's Confirmed column itself.

Items in the roadmap marked _(waits for D-n)_ are skipped while that decision
is open **and** marked "Blocking". Everything else goes ahead on the
provisional answer, written so it is easy to change later.
